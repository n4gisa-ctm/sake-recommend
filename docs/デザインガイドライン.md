# デザインガイドライン — さけAIソムリエ

最終更新: 2026-09-14（配色をライトテーマ「生成り×藍」に改定）

## 1. デザインコンセプト

**「昼の酒蔵 — 和紙と藍染」**

白壁の酒蔵に差し込むやわらかな光。生成り（和紙）の空間に、藍染の暖簾の藍が効いている。
そこに銘柄名が雪のように静かに降り続ける。明るく清潔感がありながら、書体と縦書きの銘柄で和の趣を保つ。

- キーワード: 清潔 / 和紙 / 藍染 / 明るい入口
- 参考演出: [Word Cascade](https://river.tango-gacha.com/) の「読める単語が降る」体験。参考サイト同様のライトトーンを採用。

## 2. カラーパレット（Tailwind トークン）

| トークン | HEX | 用途 |
|---|---|---|
| `washi-50`〜`washi-300` | `#fdfaf3`〜`#efe8d8` | 背景の基調（生成り・和紙） |
| `ai-600` | `#2c4a7c` | メインアクセント（藍）。CTA・ユーザー吹き出し・降る銘柄の主色 |
| `ai-400`〜`ai-500` | `#4a6ba0`〜`#375a8f` | 藍の中間色（ホバー・シマー・降る銘柄バリエーション） |
| `sumi-900` / `sumi-700` | `#26231e` / `#33302b` | 見出し・本文テキスト（墨） |
| `sumi-500` / `sumi-300` | `#5a554c` / `#9a938a` | 補足テキスト / ヒント・プレースホルダ |
| `gold-500` / `gold-400` | `#b8954a` / `#c9a96e` | サブアクセント（降る銘柄の一部・装飾） |
| `sakura-500`〜`sakura-600` | `#c25e6e`〜`#a3455a` | ごく控えめな差し色・エラー表示 |

原則:
- 背景は必ず washi 系。真っ白（#fff）は面としては使わず、パネルの半透明白のみ許容。
- 藍 (`ai`) は「効かせ色」。面で塗るのはプライマリボタンとユーザー吹き出しのみ。
- テキストの階層は墨の濃淡でつくる: 見出し `sumi-900`、本文 `sumi-700`、補足 `sumi-500`、ヒント `sumi-300`。

## 3. タイポグラフィ

| 用途 | フォント | 補足 |
|---|---|---|
| 見出し・銘柄名・ロゴ | Noto Serif JP（`--font-serif`） | 和の格調。降る銘柄名も必ず明朝 |
| 本文・UI | Zen Kaku Gothic New（`--font-sans`） | 読みやすさ優先 |

- 見出しは `font-bold`、トラッキング広め（英字ラベルは `tracking-[0.4em]`）。
- ウェルカムの2行見出しは行間を広く取る（1行目に `mb-5〜6`）。
- 本文は 14px（`text-sm`）基準、`leading-relaxed`。

## 4. 銘柄カスケード（コア演出）の表現ルール

1. **単語がまるごと降る**。縦書き（`writing-mode: vertical-rl`）の銘柄名が上から下へ流れ、1文字ずつには分解しない。
2. **不透明度**: ウェルカム/設定 0.22〜0.45（主役級に見せる）、チャット 0.1〜0.2（可読性優先）。
3. 色は藍2種（`#2c4a7c` / `#4a6ba0`）＋金（`#b8954a`）を基調に、約1割だけ桜（`#c25e6e`）を混ぜて単調さを避ける。
4. 文字サイズ 15〜35px・落下時間 12〜28秒。**負の animation-delay** で初回表示から画面全体に降っている状態にする。
5. チャット画面ではタップでその銘柄への質問が送信される（座標判定・`data-sake`属性）。
6. `prefers-reduced-motion: reduce` では非表示にする。

## 5. コンポーネント表現

- **面**: パネルはガラスモーフィズム（`glass-panel`: 半透明の白 + blur）。角丸は大きめ（`rounded-2xl`〜`rounded-3xl`）。影は `shadow-ai-800/5` 程度のごく淡い藍影。
- **枠線**: `border-ai-500/15`〜`/20` の極細藍。フォーカス/ホバーで `/40`〜`/45` へ。
- **ボタン**: プライマリは `ai-600` 面 + `washi-50` 文字。ホバーで `ai-500` + `scale-105`、アクティブで `scale-95`。
- **吹き出し**: ユーザーは藍面・右寄せ、AIは白パネル・左寄せ。AIアバターは「酒」の一文字（明朝・藍）。
- **モーション**: 出現は `fadeInUp` / `scaleIn`（0.5〜0.7s、`cubic-bezier(0.22,1,0.36,1)`）。装飾の発光は `glowPulse` でゆっくり呼吸させる。

## 6. 文言（トーン＆マナー）

- 相手は「日本酒に興味が出てきた20代後半の男性・初心者」。**専門用語で突き放さない**が、子ども扱いもしない。丁寧語ベースで、少しだけ趣のある言い回しを許容する。
- NG例: 「女子会に合う日本酒」→ ターゲットとずれる文言は使わない。
- サジェストは「初心者の背中を押す」「知ってる銘柄を深掘りする」「シーン（居酒屋・家飲み・食事）に紐づく」の3系統から構成する。

## 7. レイアウト

- コンテンツ最大幅: チャットは `max-w-2xl`、ウェルカムは `max-w-lg` 中央寄せ。
- 余白は広めに。詰め込まない（1画面1メッセージ）。
- モバイル（375px）ファースト。カスケードの列数は画面幅に応じて減らす。
